# IfcPath Web Viewer

Fast web consumer for IFC + INAV. The geometry/navigation kernel remains in Python; this application visualizes the portable result.

## Direction
- That Open / Fragments: BIM visualization
- Three.js: INAV terrain/navmesh, routes and agents
- Click start/end: XYZ surface routing integration
- Crowd layer: mesh-independent agent rendering; CC0 GLB assets can be swapped without changing simulation code

Run: `npm install && npm run dev`
